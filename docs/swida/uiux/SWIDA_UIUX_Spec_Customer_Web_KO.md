# UI/UX 화면 정의서

## SWIDA — Customer Web

- **버전**: 1.0
- **작성일**: 2026-03-26
- **기반 문서**: SWIDA PRD v1.1, TSD v1.1, FSD (Customer Web) v1.0
- **범위**: MVP — 고객 대상 업체 탐색 웹 애플리케이션
- **타겟**: Mobile-First 반응형 (3단 구조)
- **비고**: 색상, 타이포그래피, 간격 수치, 아이콘 스타일은 별도 디자인 시스템 문서에서 정의한다. Figma 프레임은 시각적 참고 자료로만 사용하며, 모든 기능적 결정은 FSD를 기준으로 한다.

---

## 1. 문서 개요

### 1.1 목적

본 문서는 SWIDA Customer Web 애플리케이션의 화면 구성, 반응형 동작, 컴포넌트 구조, 인터랙션 흐름을 페이지별로 정의한다. 기능 명세 및 비즈니스 규칙은 FSD에서 정의하며, 디자인 토큰은 디자인 시스템 가이드를 참조한다.

### 1.2 범위

| 다루는 것                          | 다루지 않는 것                |
| ---------------------------------- | ----------------------------- |
| 3단 반응형 레이아웃 셸              | 색상, 타이포그래피, 간격 수치 |
| 페이지별 화면 구조 (와이어프레임 수준) | 애니메이션 속도 / easing 곡선 |
| 컴포넌트 Tier별 대응 규칙           | 고객사별 테마                 |
| 사용자 인터랙션 흐름 (스토리보드)    | Admin Web UI                  |
| 상태별 화면 분기                    | 백엔드 설정                   |
| Figma–FSD 충돌 해결 로그            |                               |

## 2. 반응형 레이아웃 시스템

### 2.1 브레이크포인트

| Tier    | 약어 | 기준 디바이스        |
| ------- | ---- | -------------------- |
| Desktop | D    | PC, 대형 모니터       |
| Tablet  | T    | iPad, 소형 노트북     |
| Mobile  | M    | 스마트폰              |

레이아웃은 Desktop, Tablet, Mobile 세 단계로 반응형 적용된다. 컴포넌트는 모바일 우선으로 설계한 뒤 큰 화면으로 확장한다.

- 화면 정의 시 Mobile → Tablet → Desktop 순서를 따른다

> 상세 기술 사양(브레이크포인트 값, CSS 구현 등)은 TSD를 참조한다.

### 2.2 레이아웃 셸 매트릭스

| 구성 요소           |     Desktop      |       Tablet        |     Mobile      |
| ------------------- | :--------------: | :-----------------: | :-------------: |
| Header (상단 고정)  |   ✅ 전체 내비   |    ✅ 축약형        |   ✅ 최소형     |
| 검색 탭 바          | ✅ 6탭 인라인    | ✅ 6탭 (컴팩트)     |    ❌ 숨김      |
| 모바일 하단 내비    |        ❌        |         ❌          |       ✅        |
| 햄버거 드로어       |        ❌        |   ✅ (☰ 트리거)    | ✅ (☰ 트리거)  |
| Footer              |   ✅ 4컬럼       |     ✅ 2컬럼        |  ✅ 아코디언    |

## 3. 공통 셸 컴포넌트

### 3.1 Header

#### Desktop Header

```
┌────────────────────────────────────────────────────────────────────┐
│ [Logo]  [지역,업체명,테마를 검색해보세요 🔍]  [업체검색▾] [이벤트] [게시판▾] [파트너십 문의] [로그인] [회원가입] │  ← 비로그인
│ [Logo]  [지역,업체명,테마를 검색해보세요 🔍]  [업체검색▾] [이벤트] [게시판▾] [파트너십 문의] [👤]            │  ← 로그인
└────────────────────────────────────────────────────────────────────┘
```

| 요소                     | 비로그인                       | 로그인                   |
| ------------------------ | ----------------------------- | ----------------------- |
| Logo                     | ✅ → 홈페이지                  | ✅ → 홈페이지            |
| 검색바 (빠른 검색)        | ✅ 이름 검색 (F-NAV-02)        | ✅ 이름 검색             |
| 업체 검색 ▾ (드롭다운)    | ✅ → 검색 모드 드롭다운        | ✅                       |
| 이벤트                    | ✅ → 이벤트 & 공지사항         | ✅                       |
| 게시판 ▾ (드롭다운)       | ✅ → 게시판 드롭다운           | ✅                       |
| 파트너십 문의              | ✅ → 파트너십 페이지           | ✅                       |
| 로그인 / 회원가입          | ✅ → 로그인 / 회원가입 페이지  | —                        |
| 사용자 아바타 👤           | —                              | ✅ → 사용자 메뉴 드롭다운 |
| 언어 전환                  | ✅ ko/en 토글 (F-I18N-04)     | ✅                       |

**업체 검색 드롭다운**: 상세 검색, 테마별 검색, 지역 검색, 내주변 검색

**게시판 드롭다운**: 업체 추천, 마사지 정보, 커뮤니티

**사용자 메뉴 드롭다운** (로그인): 마이페이지, 로그아웃

#### Tablet Header

```
┌────────────────────────────────────────────────────────────────────┐
│ [☰] [Logo]  [지역,업체명,테마를 검색해보세요 🔍]          [로그인]          │  ← 비로그인
│ [☰] [Logo]  [지역,업체명,테마를 검색해보세요 🔍]          [👤]              │  ← 로그인
└────────────────────────────────────────────────────────────────────┘
```

| Desktop 대비 차이점   | 설명              |
| --------------------- | ----------------- |
| ☰ 추가               | 드로어 트리거      |
| 내비게이션 링크 숨김   | 드로어로 이동      |
| 검색바                 | 유지 (너비 축소)   |

#### Mobile Header

```
┌──────────────────────────────┐
│ [☰] [Logo]        [로그인]    │  ← 비로그인
│ [☰] [Logo]        [👤]        │  ← 로그인
└──────────────────────────────┘
```

- 검색바 숨김 — 하단 내비게이션 "검색" 탭 또는 드로어에서 접근
- 모든 내비게이션 링크는 드로어 및 하단 내비게이션으로 이동

### 3.2 검색 탭 바 — Desktop & Tablet

Header 하단에 표시되는 수평 탭 바로, 검색 관련 페이지에서 사용한다.

```
┌──────────┬──────────┬──────────┬──────────┬──────────┬──────────┐
│ 🔍 상세검색│ 💆 테마별검색│ 📍 지역별검색│ 📡 내주변검색│ ⭐ 리뷰 │ 🤝 파트너십 문의 │
└──────────┴──────────┴──────────┴──────────┴──────────┴──────────┘
```

| 동작        | 설명                                |
| ----------- | ----------------------------------- |
| 활성 상태   | 현재 탭 배경 채우기 (주황색)         |
| 클릭        | 해당 페이지로 이동                   |
| Desktop     | 6탭 아이콘 + 라벨, 전체 너비         |
| Tablet      | 6탭 아이콘 + 라벨, 컴팩트            |
| Mobile      | 숨김 — 하단 내비게이션으로 대체       |

### 3.3 하단 내비게이션 바 — Mobile 전용

```
┌──────┬──────┬──────┬──────┬──────┐
│  🏠  │  🔍  │  📡  │  📋  │  👤  │
│  홈  │  검색 │ 내주변 │ 게시판│  MY  │
└──────┴──────┴──────┴──────┴──────┘
```

| 탭     | 동작                                      |
| ------ | ----------------------------------------- |
| 홈     | → 홈페이지                                |
| 검색   | → 상세 검색                               |
| 내주변 | → 주변 검색                               |
| 게시판 | → 게시판 (업체 추천)                       |
| MY     | 비로그인 → 로그인 / 로그인 → 마이페이지    |

| 동작                | 설명                           |
| ------------------- | ------------------------------ |
| 고정                | 뷰포트 하단, 항상 표시          |
| 활성 표시            | 아이콘 + 라벨 하이라이트        |
| 스크롤 시 숨김       | 선택 사항 — 상단 스크롤 시 표시  |

### 6.4 리뷰 신고

> FSD: §11.3, F-REV-11~14

- **트리거**: 각 리뷰 카드의 "신고" 버튼
- **인증**: 로그인 필수

- **표시**: Tier별 인라인 드롭다운 또는 소형 모달

- **제출**: "게시하기" 버튼
- **Mobile**: FAB → 작성 폼이 포함된 바텀 시트

## 13. 상태 기반 화면 분기

### 13.1 인증 상태

| 상태               | Header 표시               | 접근 가능 페이지                              | 제한 동작                                                                                |
| ------------------ | ------------------------- | --------------------------------------------- | --------------------------------------------------------------------------------------- |
| 비로그인 (Guest)   | 로그인 / 회원가입 버튼     | 전체 페이지 (열람만)                           | 리뷰 제출/신고 → 로그인으로 리다이렉트. 마이페이지 / 프로필 수정 → 로그인으로 리다이렉트. |
| 활성 (로그인)      | 사용자 아바타 👤           | 전체 페이지 + 리뷰 작성 + 마이페이지           | 로그인/회원가입 → 홈페이지로 리다이렉트                                                  |
| 정지/잠김          | 사용자 아바타 👤           | 전체 페이지 (열람만) + 마이페이지 (조회만)      | 리뷰 제출/신고 → 오류: "계정이 정지되었습니다."                                          |

#### 스토리보드: 비로그인 → 보호된 동작

```
[1] 비로그인 사용자가 보호된 동작 시도 (예: "리뷰 작성")
[2] → 로그인 페이지로 리다이렉트 (/[locale]/auth/login)
[3] → 로그인 성공
[4] → 동작을 시도했던 페이지로 리다이렉트 (F-AUTH-05)
```

### 13.2 데이터 상태

| 상태         | 처리                                                                   |
| ------------ | ---------------------------------------------------------------------- |
| 로딩         | 스켈레톤 UI (콘텐츠 레이아웃에 맞춘 회색 플레이스홀더 블록)              |
| 데이터 없음  | 빈 상태 아이콘 + 메시지 + 제안 (예: "검색 결과가 없습니다")              |
| 오류         | 토스트 알림 + 재시도 버튼                                               |
| 목록 끝      | "더 이상 데이터가 없습니다" 또는 남은 개수가 표시된 더 보기 버튼          |
