# UI/UX 화면 정의서

## SWIDA — Admin Web

- **버전**: 1.0
- **작성일**: 2026-03-26
- **기반 문서**: SWIDA PRD v1.1, TSD v1.1, Admin Web FSD v1.0
- **범위**: MVP — 관리자 대상 플랫폼 관리 웹 애플리케이션
- **타겟**: Desktop 전용 (데스크톱 사용을 위한 최소 지원 화면 너비)
- **Figma**: 미제공 — 향후 개정 시 추가 예정
- **비고**: 색상, 타이포그래피, 간격 수치, 아이콘 스타일 등 디자인 시스템은 별도 문서에서 정의. 모든 기능적 결정은 Admin Web FSD를 기준으로 한다.

---

## 1. 문서 개요

### 1.1 목적

본 문서는 SWIDA Admin Web 애플리케이션의 화면 구성, 컴포넌트 구조, 인터랙션 흐름을 페이지별로 정의한다. Admin Web은 SWIDA 플랫폼의 일상 운영을 위한 전용 관리 인터페이스이다.

### 1.2 범위

| 다루는 것 | 다루지 않는 것 |
|---|---|
| Desktop 레이아웃 셸 | 색상, 타이포그래피, 간격 수치 |
| 페이지별 화면 구조 (와이어프레임 수준) | 애니메이션 속도 / easing 곡선 |
| 컴포넌트 패턴 (테이블, 폼, 모달, 다이얼로그) | Customer Web UI |
| 관리자 인터랙션 흐름 (스토리보드) | 백엔드 시스템 관리 패널 |
| 상태별 화면 분기 | |

### 1.3 디자인 원칙

| 원칙 | 설명 |
|---|---|
| Desktop 전용 | 데스크톱 사용을 위한 최소 지원 화면 너비. 모바일 최적화 불필요 |
| 데이터 밀집형 | 정보 밀도 우선 — 테이블, 필터, 통계 중심 |
| 사이드바 내비게이션 | 모든 페이지에서 좌측 사이드바 고정 |
| 확인 우선 | 모든 파괴적 행위 (숨기기, 삭제, 잠금, 비공개) 시 확인 다이얼로그 필수 |
| 영문 UI | 모든 관리자 인터페이스 텍스트는 영어 |

## 2. 레이아웃 시스템

### 2.1 뷰포트

표준 데스크톱 모니터에 최적화. 수직 스크롤만 — 지원 화면 크기에서 수평 스크롤 없음.

> 자세한 기술 사양은 TSD 참조.

반응형 브레이크포인트 없음 — 단일 Desktop 레이아웃. 브라우저 창이 너무 좁으면 안내 표시: "Admin Web is optimized for desktop browsers."

### 2.2 레이아웃 셸

```
┌──────────────────────────────────────────────────────────────────────┐
│  HEADER (상단 고정, 전체 너비)                                        │
│  [SWIDA Admin]                           [View Site ↗] [Admin ▾]     │
├──────────┬───────────────────────────────────────────────────────────┤
│  SIDEBAR │  메인 콘텐츠 영역                                         │
│  (좌측   │  ┌───────────────────────────────────────────────────┐   │
│  고정)   │  │  페이지 헤더 (제목 + 액션)                        │   │
│          │  ├───────────────────────────────────────────────────┤   │
│          │  │  페이지 바디 (테이블, 폼, 카드)                   │   │
│          │  │  (스크롤)                                         │   │
│          │  │                                                   │   │
│          │  │                                                   │   │
│          │  │                                                   │   │
│          │  └───────────────────────────────────────────────────┘   │
└──────────┴───────────────────────────────────────────────────────────┘
```

| 요소 | 동작 |
|---|---|
| Header | 전체 너비, 상단 고정 |
| Sidebar | 고정 너비, 좌측 고정. Header 제외 전체 뷰포트 높이. 콘텐츠 넘침 시 스크롤 |
| 메인 콘텐츠 | 나머지 너비 채움. 스크롤 가능. 최대 너비 내 중앙 정렬 |

> 자세한 기술 사양은 TSD 참조.

## 3. 공통 셸 컴포넌트

### 3.1 Header

```
┌──────────────────────────────────────────────────────────────────────┐
│  SWIDA Admin                                [View Site ↗] [Admin ▾]  │
└──────────────────────────────────────────────────────────────────────┘
```

| 요소 | 설명 | FSD 참조 |
|---|---|---|
| SWIDA Admin (로고/텍스트) | `/dashboard`로 링크 | F-NAV-01 |
| View Site ↗ | 새 탭에서 `www.swida.com` 열기 | F-NAV-12 |
| Admin ▾ | 드롭다운: 관리자 이름/이메일 + Logout | F-NAV-10, F-NAV-11 |

### 3.2 사이드바 내비게이션

```
┌──────────────────┐
│  📊 Dashboard     │  ← 활성 하이라이트
│                   │
│  ── Content ──    │
│  🏪 Shops         │
│  ⭐ Reviews [3]   │  ← 뱃지: under_review 수
│  💆 Themes        │
│  📍 Locations     │
│                   │
│  ── Operations ── │
│  🤝 Inquiries [5] │  ← 뱃지: 신규 문의 수
│  👥 Users         │
│                   │
│  ── System ──     │
│  📋 Audit Log     │
└──────────────────┘
```

| 동작 | 설명 |
|---|---|
| 활성 상태 | 현재 페이지가 사이드바에서 시각적으로 강조 표시 |
| 뱃지 | Reviews (under_review) 및 Inquiries (new) 실시간 카운트 뱃지 |
| 접기 | 아이콘만 표시 모드로 접기 가능. 툴팁 표시. 접기 상태는 세션 간 유지 |

### 3.3 페이지 헤더 패턴

모든 페이지는 일관된 헤더 구조를 따름:

```
┌──────────────────────────────────────────────────────────────────┐
│  페이지 제목                                    [주요 액션]       │
│  부제목/설명 (선택)                                               │
├──────────────────────────────────────────────────────────────────┤
│  [필터 바]                                                       │
└──────────────────────────────────────────────────────────────────┘
```

### 3.4 공통 UI 패턴

#### 데이터 테이블

모든 목록 페이지는 일관된 테이블 패턴을 사용:

```
┌──────────────────────────────────────────────────────────────────┐
│  [검색 입력]  [필터: Status ▾]  [필터: ... ▾]        [정렬 ▾]   │
├───────┬──────────┬────────┬───────┬────────┬─────────┬──────────┤
│  ☐    │ 컬럼 1   │ 컬럼 2 │ 컬럼 3│ 컬럼 4 │ 상태    │ 액션     │
├───────┼──────────┼────────┼───────┼────────┼─────────┼──────────┤
│  ☐    │ 데이터   │ 데이터  │ 데이터│ 데이터  │ [뱃지]  │ [⋯]     │
│  ☐    │ 데이터   │ 데이터  │ 데이터│ 데이터  │ [뱃지]  │ [⋯]     │
│  ☐    │ 데이터   │ 데이터  │ 데이터│ 데이터  │ [뱃지]  │ [⋯]     │
├───────┴──────────┴────────┴───────┴────────┴─────────┴──────────┤
│  1-10 / 234 표시 중              [10▾] 페이지당   [< 1 2 3 4 5 >]│
└──────────────────────────────────────────────────────────────────┘
```

| 기능 | 설명 |
|---|---|
| 체크박스 컬럼 | 일괄 작업을 위한 행 선택 |
| 액션 컬럼 | "⋯" 메뉴 또는 인라인 아이콘 버튼 (편집, 미리보기 등) |
| 페이지네이션 | 페이지 번호 + 페이지 크기 설정 (10, 20, 50) |
| 로딩 | 콘텐츠 로딩 중 로딩 표시기 표시 |
| 빈 상태 | 테이블 본문 중앙에 "No results found" 표시 |

#### 확인 다이얼로그

모든 파괴적 행위에 사용:

```
┌──────────────────────────────────────┐
│  ⚠️ Confirm Action                   │
│                                      │
│  Are you sure you want to {action}?  │
│  {추가 설명}                          │
│                                      │
│            [Cancel]  [Confirm]       │
└──────────────────────────────────────┘
```

#### 토스트 알림

- **성공**: 녹색, 5초 후 자동 닫힘
- **오류**: 빨간색, 수동 닫기까지 유지
- **위치**: 메인 콘텐츠 영역 우측 상단

#### 상태 뱃지

| 상태 | 색상 | 사용 위치 |
|---|---|---|
| Published | 녹색 | 업체, 리뷰 |
| Draft | 회색 | 업체 |
| Hidden | 노란색 | 리뷰 |
| Under Review | 주황색 | 리뷰 |
| Deleted | 빨간색 | 리뷰 |
| Active | 녹색 | 사용자 |
| Locked | 빨간색 | 사용자 |
| New | 파란색 | 문의 |
| Contacted | 시안색 | 문의 |
| Awaiting Info | 노란색 | 문의 |
| Approved | 녹색 | 문의 |
| Rejected | 빨간색 | 문의 |

## 4. 로그인 (`/login`)

> FSD: §3, F-AUTH-01~05

### 화면 구성

```
┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│                     ┌────────────────────────┐                   │
│                     │  SWIDA Admin            │                   │
│                     │                        │                   │
│                     │  Email                 │                   │
│                     │  [________________]    │                   │
│                     │                        │                   │
│                     │  Password              │                   │
│                     │  [________________]    │                   │
│                     │                        │                   │
│                     │  [Log In]              │                   │
│                     │                        │                   │
│                     │  {오류 메시지 영역}     │                   │
│                     └────────────────────────┘                   │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

- 중립 배경에 중앙 정렬 카드. 사이드바/Header 없음.
- 오류 메시지는 폼 하단에 인라인 표시.

### 스토리보드

```
[1] /login → 이미 인증된 상태면 → /dashboard로 리다이렉트 (F-AUTH-05)

[2] 이메일 + 비밀번호 입력 → [Log In]

[3a] 성공 → 사용자 세션 안전하게 저장 → /dashboard로 리다이렉트 (F-AUTH-03)
[3b] 잘못된 자격증명 → 인라인 오류: "Invalid email or password" (F-AUTH-04)
[3c] 서버 오류 → 인라인 오류: "Unable to connect to server. Please try again."

[4] 세션 만료 (모든 페이지) → /login으로 리다이렉트 + 메시지:
    "Session expired. Please log in again." (F-AUTH-07)
```

## 6. 업체 관리

### 6.1 업체 목록 (`/shops`)

> FSD: §5.1, F-SHOP-01~12

### 화면 구성

```
┌──────────────────────────────────────────────────────────────────┐
│  Shops                                          [+ Create Shop]  │
├──────────────────────────────────────────────────────────────────┤
│  [🔍 이름 검색]  [Status: All ▾]  [Region ▾]  [Theme ▾]         │
├───┬───────┬────────┬──────┬────────┬───────┬────────┬───────────┤
│ ☐ │ 썸네일│ 이름   │ 지역 │ 테마   │ ★ 평점│ 상태   │ 액션       │
├───┼───────┼────────┼──────┼────────┼───────┼────────┼───────────┤
│ ☐ │ [img] │ 골드문  │ 장안동│ 스웨디시│ 4.9   │[Published]│ [Edit][Preview][⋯]│
│ ☐ │ [img] │ 힐링스파│ 역삼동│ 아로마  │ 4.5   │[Draft]   │ [Edit][Preview][⋯]│
│ ☐ │ [img] │ ...    │ ...  │ ...    │ ...   │ ...    │ ...       │
├───┴───────┴────────┴──────┴────────┴───────┴────────┴───────────┤
│  1-10 / 1,234 표시 중         [10▾] 페이지당   [< 1 2 3 ... >]  │
└──────────────────────────────────────────────────────────────────┘
```

**행 액션 (⋯ 메뉴)**:

| 액션 | 조건 | 동작 |
|---|---|---|
| Edit | 항상 | → `/shops/[id]` |
| Preview | 항상 | 새 탭에서 Customer Web 업체 상세 열기 (F-SHOP-11) |
| Publish | 상태 = Draft | 즉시 공개 (F-SHOP-07) |
| Unpublish | 상태 = Published | 비활성 사유 다이얼로그 → 비공개 처리 (F-SHOP-08) |
| View Audit Log | 항상 | → `/audit-log?document={id}` |

- 영어 필드는 선택사항. 미입력 번역은 표시기 표시.

#### 스토리보드: 업체 등록

```
[1] /shops/new → 빈 폼. 로케일: 한국어 (기본).

[2] 관리자가 필수 필드 입력. 실시간 폼 유효성 검사:
    - 필수 필드 빈 값 → 빨간 테두리 + "Required" 라벨
    - Description 500자 초과 → 글자 카운터 빨간색
    - 테마 미선택 → 테마 섹션 인라인 오류

[3] 지도 핀 드롭:
    [3a] 관리자가 검색에 주소 입력 → 지도 중심 이동 + 핀 배치
    [3b] 관리자가 지도 클릭으로 핀 조정 → 위도/경도 필드 갱신
    [3c] 주소 미검색 → 토스트 + 수동 핀 배치

[4] 이미지 업로드:
    [4a] 드래그 앤 드롭 또는 파일 선택 → 이미지 미리보기 + 서버 업로드
    [4b] 이미지의 별 아이콘 클릭 → 썸네일로 설정
    [4c] ✕ 클릭 → 이미지 제거 (썸네일인 경우 확인)
    [4d] 5MB 초과 → 오류 토스트: "Image file is too large. Maximum size: 5MB."

[5] 서비스 메뉴:
    [5a] "+ 항목 추가" → 빈 필드의 새 행
    [5b] 이름, 시간, 가격 입력 → 유효성 검사 (모두 필수)
    [5c] "✕" → 행 제거 (마지막 남은 항목인 경우 확인)

[6a] "Save Draft" → 초안으로 저장 → 성공 토스트 → /shops/[id]로 리다이렉트
[6b] "Save & Publish" → 저장 및 공개 → 성공 토스트 → /shops/[id]로 리다이렉트
[6c] 유효성 검사 실패 → 첫 번째 오류로 스크롤 + 인라인 오류 메시지

[7] 로케일 전환 → 한국어 먼저 저장 → 영어로 전환 → 선택적 번역 입력
```

### 6.3 업체 수정 (`/shops/[id]`)

> FSD: §5.3, F-SHOP-28~35

업체 등록과 동일한 레이아웃에 다음 추가:

| 추가 사항 | 설명 |
|---|---|
| 기존 데이터 미리 입력 | 모든 폼 필드에 현재 데이터 로드 (F-SHOP-28) |
| 공개/비공개 토글 | 페이지 헤더에 위치. 공개 업체는 "Unpublish" 표시 (사유 다이얼로그 트리거). 초안 업체는 "Publish" 표시 (F-SHOP-31) |
| 미리보기 버튼 | 페이지 헤더에 위치. Customer Web 새 탭에서 열기 (F-SHOP-32) |
| Last Verified Date | 폼 내 추가 날짜 선택 필드 (F-SHOP-33) |
| 감사 이력 링크 | 페이지 헤더 → `/audit-log?document={id}` (F-SHOP-35) |
| 로케일 표시기 | 어떤 로케일에 저장된 콘텐츠가 있는지 표시 (F-SHOP-34) |

**행 액션 (⋯ 메뉴)**:

| Hide | published, under_review | 사유 다이얼로그 → 상태 → hidden (F-REV-08) |
| Delete | published, hidden, under_review | 확인 다이얼로그 → 상태 → deleted (F-REV-10) |
| View Author | 전체 | → `/users?search={author}` (F-REV-11) |

│  [▾ 사유 선택                  ]     │

│                                      │
│            [Cancel]  [Hide Review]   │

```

**일괄 작업** (F-REV-12): 여러 행 선택 → "Bulk" 드롭다운 → Hide / Delete. 확인 다이얼로그에 건수 표시.

### 스토리보드: 리뷰 관리

```
[1] /reviews → 기본: 전체 리뷰, 최신순 정렬

[2] "Under Review" 필터 → 관리자 확인 필요 리뷰 표시

[3] 리뷰 펼치기 → 전체 댓글 + 신고 사유 + 작성자 정보 확인

[4a] "Publish" → 상태 변경 → Customer Web에 표시 → 평점 재계산
[4b] "Hide" → 사유 다이얼로그 → 확인 → 리뷰 숨김 → 평점 재계산
[4c] "Delete" → 확인 다이얼로그 → 공개 보기에서 리뷰 제거 → 평점 재계산

[5] "View Author" → 해당 사용자 필터로 사용자 관리 페이지 이동
    → 악용 패턴 발견 시 → 사용자 페이지에서 계정 잠금
```

[5] 관리자가 검증 → 상태를 "Approved"로 변경

[6] "Create Shop Listing" → /shops/new에 문의 데이터 자동 입력 (F-INQ-10)
    → 관리자가 등록 완료 → 저장 & 공개

[7] 문의가 공개된 업체에 연결 → 상태 자동 "Published" 설정 (F-INQ-11)

대안:
[3b] 어느 단계에서든 문의 거절 → "Reject" → 확인 → 종료 상태
```

## 13. 상태별 화면 분기

### 13.1 인증 상태

| 상태 | 동작 |
|---|---|
| 미인증 | 모든 페이지 → `/login`으로 리다이렉트 |

| 세션 만료 | 현재 작업 중단 → `/login`으로 리다이렉트 + "Session expired" 메시지 |

### 13.2 데이터 상태

| 상태 | 처리 |
|---|---|
| 로딩 | 콘텐츠 로딩 중 로딩 표시기 표시 |
| 데이터 없음 | 테이블 본문 영역 중앙에 "No results found" 표시. 필터 조정 제안 |
| 오류 (서버) | 오류 토스트: "A temporary error occurred. Please try again shortly." + 재시도 |
| 오류 (네트워크) | 오류 토스트: "Please check your network connection." |
| 유효성 검사 오류 | 인라인 필드 레벨 오류 (빨간 테두리 + 메시지). 제출 시 첫 번째 오류로 스크롤 |

### 13.3 파괴적 행위 확인

다음 행위는 반드시 명시적 확인 다이얼로그 필요:

| 행위 | 다이얼로그 메시지 |
|---|---|
| 업체 비공개 | "이 업체는 Customer Web에서 즉시 숨겨집니다." + 사유 선택 |
| 리뷰 숨기기 | "이 리뷰는 공개 보기에서 제거됩니다." + 사유 선택 |
| 리뷰 삭제 | "이 리뷰는 공개 보기에서 영구 제거됩니다." |
| 사용자 잠금 | "이 사용자는 리뷰 및 콘텐츠 작성이 불가능해집니다." + 사유 선택 |
| 테마 삭제 | "이 테마는 영구 삭제됩니다." (업체 태그 시 차단) |
| 지역/시군구 삭제 | "영구 삭제됩니다." (하위 항목 존재 시 차단) |
| 문의 거절 | "이 문의는 거절 처리됩니다." |

## 14. 인터랙션 패턴 요약

### 14.1 CRUD 패턴

모든 관리 페이지는 동일한 인터랙션 루프를 따름:

```
목록 (테이블) → 등록/수정 (폼) → 저장 → 목록 복귀 (토스트 표시)
                                ↘ 미리보기 (새 탭, Customer Web 뷰)
```

### 14.2 인라인 vs 모달 vs 페이지

| 패턴 | 사용 대상 |
|---|---|
| 전체 페이지 폼 | 업체 등록, 업체 수정 (복잡, 다수 폼 섹션) |
| 모달/다이얼로그 | 테마 생성/편집, 리뷰 상세, 사용자 상세, 확인 |
| 인라인 펼침 | 감사 로그 diff, 위치 시/군/구 목록, 문의 상세 |
| 드롭다운 메뉴 | 행 액션 (⋯), 상태 변경 |

### 14.3 페이지 간 내비게이션

| 출발 | 링크 | 도착 |
|---|---|---|
| Dashboard → 신규 문의 알림 | → | `/inquiries?status=new` |
| Dashboard → 검토 대기 리뷰 알림 | → | `/reviews?status=under_review` |
| Dashboard → 업체 등록 | → | `/shops/new` |
| 업체 수정 → 감사 이력 | → | `/audit-log?document={shopId}` |
| 리뷰 행 → 작성자 보기 | → | `/users?search={authorName}` |
| 사용자 행 → 리뷰 보기 | → | `/reviews?author={userId}` |
| 문의 → 업체 등록 생성 | → | `/shops/new?from_inquiry={inquiryId}` |
