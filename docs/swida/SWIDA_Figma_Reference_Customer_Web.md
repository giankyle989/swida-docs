# Customer Web — Figma Design Reference

> **📌 Primary Rule:** Before writing any frontend code or making UI decisions, **always consult the Figma designs listed here first.** These are the single source of truth for all Customer Web screens.

---

## ⚠️ Pre-Flight Check — MCP Figma Server

> **🔴 STOP. Do not proceed with any frontend development until this check passes.**

Before opening any Figma link or writing a single line of UI code, verify that the **Figma MCP server is connected**:

1. Check your MCP server list for an active **Figma** connection.
2. If Figma MCP is connected ✅ — proceed to development.
3. If Figma MCP is **not** connected ❌ — **stop immediately**. Do not guess, approximate, or proceed from memory.

### What to do if Figma MCP is not connected

- Go to your MCP settings / tools panel and enable the Figma MCP server.
- Re-confirm the connection before continuing.
- If you are unable to connect, escalate to the team lead or design team — **do not build screens without verified Figma access**.

> **Why this matters:** The Figma MCP server is what allows direct inspection of design tokens, spacing, assets, and component states from the team library. Developing without it risks diverging from the approved designs and creating rework.

---

## How to Use This Document

1. ✅ Confirm Figma MCP server is connected (see above).
2. Identify the screen or feature you are building.
3. Open the corresponding Figma link below.
4. Inspect spacing, typography, colors, component states, and interactions directly in Figma.
5. Only deviate from the design if explicitly approved by the design team.

## Developer Guidelines

### ✅ Do

- **Always verify the Figma MCP server is connected before starting any work.** If it's not connected, stop and reconnect before proceeding.
- Open Figma and inspect the exact node before building any screen.
- Follow the spacing, font sizes, and color tokens defined in the Figma team library.
- Check for component variants and interactive states (hover, active, disabled, error) in Figma.
- Use Figma's **Dev Mode** (if available) to get CSS values and asset exports directly.
- When a new screen is added to Figma, update this document with the new node link.

### ❌ Don't

- **Don't proceed with development if the Figma MCP server is not connected** — no exceptions.
- Don't guess layouts from memory — always verify against the Figma link.
- Don't create custom styles that aren't defined in the Figma team library without design approval.
- Don't use placeholder assets in production; export final assets from Figma.
